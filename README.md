# Sistema-de-automatizacion-de-CTFs

## Requistos

Tener docker y el plugin docker-compose instalado.

## Ejecutar el programa

Para levntar el sistema entero con ejecutar start.sh vale. Se necesita los permisos de Docker, para levantar los contenedores.

## Inicio

Una vez que los 2 contenedores estan activos. Ir a "http://localhost:8000/" para ir a login principal. Puede usar las credenciales "admin":"admin". Modificar la contraseña es el primer paso recomendable.
